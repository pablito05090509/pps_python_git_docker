# La Bayeta de la Fortuna 🧽🍀

Aplicación web sencilla inspirada en las galletas de la fortuna y servilletas de bar.
Cada vez que accedas, te mostrará una frase auspiciosa aleatoria.
## Ejecución del proyecto

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Uso de la aplicación web

- Abrir navegador en http://127.0.0.1:5000/ → devuelve "Hola, mundo"
- Endpoint /frotar/N → devuelve N frases aleatorias
  Ejemplo: http://127.0.0.1:5000/frotar/3
